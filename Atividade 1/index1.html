INF 321 - Projeto e Desenvolvimento de Sistemas Para a Web

OBJETIVOS – Introduzir ao aluno conceitos arquiteturais básicos da Web, focando em aspectos de projeto e implementação de sistemas e softwares para a mesma; Treinar o desenvolvimento de aplicações cliente-servidor e de sistemas com comunicação por troca de mensagens; Treinar o desenvolvimento de aplicações multiplataforma; Introduzir o aluno à linguagens de marcação e de folhas de estilo; Prover contato inicial do estudante com tecnologias de desenvolvimento backend; Introduzir, por meio de aplicações Web, conceitos de comunicação assíncrona cliente-servidor e acesso a bancos de dados no servidor.

EMENTA – Introdução à Web. Linguagens para Desenvolvimento frontend. Linguagens e Frameworks para Desenvolvimento backend. Introdução à Middleware. Tópicos Avançados em Web.

Conteúdos Abordados

  • HTML – Linguagem de marcação que funciona como o esqueleto de qualquer página web. É por meio de suas tags que você define a estrutura e o conteúdo do site, inserindo elementos essenciais como textos, títulos, parágrafos, imagens, links e formulários de forma organizada.

  • CSS – Linguagem de estilos responsável por toda a parte visual e estética do site. Enquanto o HTML cria a estrutura, o CSS define as cores, as fontes, o espaçamento e a disposição dos elementos na tela, permitindo adaptar o design para celulares, tablets e computadores de forma elegante.

  • JavaScript – Linguagem de programação que traz vida, dinamismo e interatividade para as páginas web. Com ele, você consegue criar elementos que reagem às ações do usuário, como menus que abrem e fecham, animações complexas, validação de formulários em tempo real e atualizações de conteúdo sem precisar recarregar a página.

  • Elixir – Linguagem de programação moderna e poderosa, focada no desenvolvimento de sistemas robustos e de alto desempenho no lado do servidor (backend). Criada por um brasileiro, ela se destaca por lidar com milhares de acessos simultâneos sem travar, sendo muito utilizada para construir aplicativos em tempo real, chats e sistemas que nunca podem sair do ar.
